# Portfolio

A personal developer portfolio built from scratch with vanilla HTML, CSS, and JavaScript — featuring a dual-theme design system: a Matrix-inspired hacker aesthetic in dark mode, and a chrome/holographic Y2K aesthetic in light mode.

🔗 **Live site:** https://agentred1999.github.io/portfolio/

## Features

- 🌙 **Dark mode** — Matrix digital rain background, cyan neon accents, terminal-style typography
- ☀️ **Light mode** — Chrome/silver gradients, frosted glass panels, glossy Y2K-inspired UI
- 🎨 Smooth animated theme-switch transition
- 📱 Fully responsive layout
- ♿ Keyboard-accessible navigation with visible focus states
- 🖱️ Cursor-follow glow effect
- 📄 Categorized skills section
- 🔗 Live project links and downloadable resume
- 🥚 Hidden Easter egg (try the Konami code)

## Tech Stack

- HTML5
- CSS3 (custom properties, backdrop-filter, CSS Grid/Flexbox)
- Vanilla JavaScript (ES6+)
- Canvas API (Matrix rain animation)

## Sections

- **Home** — Hero introduction with photo ID card and quick-access buttons
- **Projects** — Featured work with live links
- **About** — Bio and categorized technical skills
- **Contact** — Ways to get in touch
